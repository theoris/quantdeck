## 🖥️ ความต้องการของระบบ (System Requirements)

- **ระบบปฏิบัติการ:** Windows 10 / 11 (64-bit)
- **สภาพแวดล้อมรันไทม์:** Python **3.12** (x64) หากเครื่องยังไม่มี ตัว Launcher จะมีคำแนะนำช่วยติดตั้งให้อัตโนมัติในการเปิดครั้งแรก
- **เบราว์เซอร์แสดงผล:** Google Chrome หรือ Microsoft Edge (QuantDeck จะเปิดเป็นหน้าต่างแอปพลิเคชันเดสก์ท็อปที่ลื่นไหลไร้แถบกวนใจ)
- **ฮาร์ดแวร์:** หน่วยความจำ RAM ขั้นต่ำ 4 GB (แนะนำ 8 GB ขึ้นไปสำหรับการดูกราฟหลายจอ รันโมเดล ML และทำแบ็กเทสต์ความเร็วสูง)
- **การเชื่อมต่อโบรกเกอร์ (ตามต้องการ):** MetaTrader 5 Terminal, cTrader Open API Credentials, SimpleFX API หรือ Settrade Open API

## ⚙️ วิธีการติดตั้งและการเริ่มใช้งานด่วน

### วิธีที่ 1 — ติดตั้งด้วยตัว Setup (`.exe`)
1. ดาวน์โหลดไฟล์ **`QuantDeck_Standalone_Setup.exe`**
2. ดับเบิลคลิกเปิดไฟล์ติดตั้ง
   > *หมายเหตุ:* หาก Windows SmartScreen แสดงข้อความเตือน *"Windows protected your PC"* (เนื่องจากเป็นโปรแกรมที่เพิ่งปล่อยใหม่) ให้คลิกที่ **More info → Run anyway**
3. เลือกโฟลเดอร์ปลายทางที่ต้องการแล้วกด **Install & Launch** ตัวโปรแกรมจะสร้างทางลัดบน Desktop และ Start Menu ให้โดยอัตโนมัติ
4. QuantDeck จะเริ่มสตาร์ทระบบหลังบ้านและเปิดหน้าต่างกราฟขึ้นมาทันที

### วิธีที่ 2 — ใช้งานแบบพกพา (`.zip`)
1. ดาวน์โหลดไฟล์ **`QuantDeck_Standalone_Release.zip`**
2. แตกไฟล์ ZIP ไปยังโฟลเดอร์ที่ต้องการ (เช่น `C:\QuantDeck` หรือ External Drive) *ควรหลีกเลี่ยงโฟลเดอร์ที่มีการจำกัดสิทธิ์ เช่น `C:\Program Files`*
3. ดับเบิลคลิกที่ **`QuantDeck.exe`** (หรือดับเบิลคลิก `run_chart.bat`)
4. ในการเปิดใช้งานครั้งแรก ระบบจะทำการตรวจสอบและเตรียมแพ็กเกจ Python จาก `requirements.txt` เมื่อเสร็จแล้วการเปิดครั้งต่อไปจะเร็วขึ้นในไม่กี่วินาที

### การตั้งค่าเริ่มต้นใน 5 นาที
1. **เลือกภาษา:** สลับภาษาที่ต้องการใช้งานได้ทันทีจากแถบด้านขวาของหน้าจอ
2. **ตั้งค่าแหล่งข้อมูลและโบรกเกอร์:** เปิดเมนู **Source Settings** ที่แถบเมนูด้านบน:
   - **Yahoo Finance:** พร้อมใช้งานทันทีสำหรับหุ้นสหรัฐฯ ดัชนีโลก และทองคำโดยไม่ต้องใส่คีย์ใดๆ
   - **MetaTrader 5:** เพียงเปิดโปรแกรม MT5 ของคุณและล็อกอินบัญชีไว้ QuantDeck จะเชื่อมต่อให้อัตโนมัติผ่าน Local IPC
   - **cTrader:** นำค่า Client ID, Secret และ Token จาก [https://openapi.ctrader.com/](https://openapi.ctrader.com/) มาใส่ จากนั้นกดปุ่ม **🔄 Load Linked Accounts** เพื่อดึงรายชื่อบัญชีเทรดตามเลขที่คุณคุ้นเคยได้ทันที
   - **SimpleFX / Binance / Polygon / SET:** ใส่ข้อมูลบัญชีและกดปุ่ม **Test Connection**
3. **เปิดระบบส่งคำสั่งเทรด (ระบบความปลอดภัย):** ติ๊กถูกที่ช่อง **⚡ Enable Live Trading** ของโบรกเกอร์ที่ต้องการส่งคำสั่ง (ระบบจะปิดไว้เป็นค่าเริ่มต้นเพื่อความปลอดภัยของผู้ใช้)
4. **Toolbox:** ตรวจสอบออเดอร์ ตำแหน่งถือครอง ประวัติการเทรด และสถิติ Margin ได้ที่แผงด้านล่าง

## ⌨️ คีย์ลัดและการสั่งการที่สำคัญ

| คีย์ลัด / การทำงาน | คำอธิบายการใช้งาน |
| :--- | :--- |
| **`F5`** | **รีเฟรชหน้าต่าง / เชื่อมต่อระบบใหม่ทันที:** ใช้กดเมื่อพบอาการค้าง กราฟไม่ขยับ หรือกระตุก ระบบจะรีเฟรชหน้าจอ เชื่อมต่อ WebSocket ใหม่ และดึงข้อมูลออเดอร์ล่าสุดให้ทันที |
| **`Ctrl + N`** | **เปิดหน้าต่างโปรแกรมใหม่:** เปิดหน้าต่าง QuantDeck เพิ่มอีกหนึ่งหน้าต่างอย่างอิสระ เหมาะสำหรับการลากไปใช้งานบนหน้าจอที่ 2 หรือ 3 |
| **`Delete` / `Backspace`** | ลบเส้นวาดหรือเครื่องมือวิเคราะห์ที่กำลังถูกเลือกอยู่บนกราฟ |
| **`Esc`** | ยกเลิกโหมดการวาด หรือคืนค่าเคอร์เซอร์กลับสู่ลูกศรปกติ |
| **`คลิกที่แถวรายการใน Toolbox`** | สลับหน้าจอกราฟหลักไปยังคู่เงินและโบรกเกอร์ของออเดอร์นั้นโดยอัตโนมัติ |
| **`ลากเส้น SL / TP บนกราฟ`** | ลากปรับระดับราคา Stop Loss หรือ Take Profit ได้แบบเรียลไทม์บนกราฟแท่งเทียน |
| **`คลิกปุ่ม '×' บนเส้นกราฟ`** | ยกเลิกหรือล้างค่า Stop Loss / Take Profit ของออเดอร์นั้นทันที |

## 🛠️ การแก้ไขปัญหาเบื้องต้น (Troubleshooting)

> [!TIP]
> **หากพบปัญหาหน้าจอค้าง กราฟไม่โหลด หรือการเชื่อมต่อสะดุด?**  
> เพียงกดปุ่ม **`F5`** บนคีย์บอร์ด ระบบจะทำการเชื่อมต่อ WebSocket และดึงข้อมูลใหม่ทันทีโดยที่คุณไม่ต้องรีสตาร์ทโปรแกรมหลังบ้านใหม่

| ปัญหาที่พบ | แนวทางแก้ไข |
| :--- | :--- |
| **กราฟกระตุกหรือราคาไม่ขยับ** | กดปุ่ม **`F5`** เพื่อรีเฟรชและเชื่อมต่อระบบส่งข้อมูลราคาแบบสดใหม่อีกครั้ง |
| **ต้องการดูกราฟแยกหลายหน้าจอ** | กด **`Ctrl + N`** เพื่อเปิดหน้าต่างใหม่แล้วลากไปยังหน้าจอที่สองของคุณได้ทันที |
| **หน้าต่างโปรแกรมไม่เปิดขึ้นมา** | ตรวจสอบว่าในเครื่องมี Google Chrome หรือ Microsoft Edge หรือพิมพ์ `http://127.0.0.1:8765` บนเบราว์เซอร์ด้วยตนเอง |
| **แจ้งเตือน "Port 8765 already in use"** | ดับเบิลคลิกที่ **`Kill_QuantDeck.exe`** เพื่อปิดโปรเซสที่ค้างอยู่ แล้วจึงเปิดโปรแกรมใหม่อีกครั้ง |
| **สถานะ MT5 ขึ้นว่า Disconnected** | ตรวจสอบว่าเปิดโปรแกรม MT5 ล็อกอินบัญชีเรียบร้อย และกดปุ่ม **Algo Trading** บน MT5 แล้วหรือไม่ |
| **cTrader ขึ้นข้อผิดพลาดการยืนยันตัวตน** | โทเค็น cTrader จะมีอายุการใช้งาน ให้ไปที่ Source Settings แล้วกดปุ่ม **🔄 Load Linked Accounts** หรือนำโทเค็นชุดใหม่มาวาง |
| **โบรกเกอร์ปฏิเสธคำสั่งซื้อขาย** | ตรวจสอบว่าได้ติ๊กถูกที่ **⚡ Enable Live Trading** ของโบรกเกอร์นั้นแล้วหรือไม่ และตรวจดูว่าบัญชีมี Free Margin เพียงพอหรือไม่ |

## ⚠️ คำเตือนเรื่องความเสี่ยงและข้อควรระวัง

- **ความเสี่ยงทางการเงิน:** การเทรด Forex, CFDs, คริปโตเคอร์เรนซี และตราสารอนุพันธ์มีความเสี่ยงสูงที่จะสูญเสียเงินทุน ควรทดสอบกลยุทธ์บนบัญชีทดลอง (Demo) ให้มั่นใจก่อนใช้เงินจริงเสมอ QuantDeck เป็นเพียงเครื่องมืออำนวยความสะดวกในการวิเคราะห์และส่งคำสั่ง มิได้ให้คำแนะนำทางการเงินใดๆ

- **การแจ้งเตือนของ Firewall:** ในการเปิดโปรแกรมครั้งแรก ให้กดอนุญาต (Allow) การเข้าถึงเครือข่ายสำหรับ Private Network เพื่อให้หน้าต่างกราฟสามารถติดต่อกับเซิร์ฟเวอร์บนเครื่องที่ `127.0.0.1` ได้
